## 📖 项目简介

云枢中台是以数据为核心、数字运营为纽带的新一代智慧园区解决方案。采用"四大中台"架构（业务中台、数据中台、物联中台、技术中台），实现技术统一、数据统一、业务统一、物联统一。

### 核心价值

- ✅ **数据互联互通**：全面汇集不同系统数据，形成企业数据资产
- ✅ **共性沉淀共享**：组件化资源复用，快速灵活构建业务
- ✅ **快速业务创新**：敏捷响应市场，快速上线与迭代试错
- ✅ **数据智能洞察**：自动化和智能化驱动业务创新
- ✅ **生态持续运营**：打通园区生态扩展，保持开放融合

## 🚀 快速开始

### 方式一：一键启动（推荐）

```
双击：快速启动.bat
选择：4. 全部启动
```

将同时启动：
- 后端服务（http://localhost:8080）
- PC 管理后台（http://localhost:5173）
- 移动应用（小程序开发服务器）

### 方式二：分步启动

```bash
# 1. 检查环境
双击 检查环境.bat

# 2. 启动后端
cd code/platform-server
mvn clean package -DskipTests
java -jar platform-admin/target/platform-admin-1.0.0.jar

# 3. 启动 PC 后台
cd code/platform-admin
npm install
npm run dev

# 4. 启动小程序
cd code/platform-app
npm install
npm run dev:mp-weixin
```

| 后端 API | http://localhost:8080 | - |

## ⚠️ 常见问题

### 后端启动失败

**问题：** 数据库连接失败  
**解决：**
1. 检查 MySQL 是否运行
2. 检查配置文件中的数据库连接信息
3. 检查防火墙设置

### 前端无法访问后端

**问题：** 跨域错误  
**解决：**
1. 检查 `vite.config.ts` 代理配置
2. 检查后端 CORS 配置
3. 确认后端服务已启动

### 设备无法接入

**问题：** MQTT 连接失败  
**解决：**
1. 检查 EMQ X 是否运行
2. 检查 MQTT Broker 地址配置
3. 检查设备认证信息
