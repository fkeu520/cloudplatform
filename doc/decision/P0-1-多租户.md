## §3 回滚开关设计

详见 `doc/backup_20260528/P0-1-回滚开关设计.md`。

**机制**: `@ConditionalOnProperty(prefix = "platform.tenant.interceptor", name = "enabled", matchIfMissing = true)`
- 默认 enabled: 拦截器生效
- 设置 `PLATFORM_TENANT_INTERCEPTOR_ENABLED=false` → 重启 → 拦截器完全跳过

**关键改进**: 9999 占位模式 → null 模式:
- 旧: `tenant_id=NULL` 时返回 `new LongValue(9999L)` — 魔法常量
- 新: `ignoreTable` 返回 `true` 时跳过 — MyBatis-Plus 原生支持
