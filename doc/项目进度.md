## 已完成

### 基础架构
- Spring Cloud 微服务体系（platform-user:8081 / auth:8082 / gateway:8083 / workflow:8084 / ops:8087 / message:8085）
- Docker Compose 编排（mysql, redis, nacos, kafka, es, logstash, kibana, minio, nginx）
- Nacos 服务注册发现 + 配置中心
- Flyway 数据库迁移管理（各服务独立迁移表）
- MyBatis-Plus 持久层 + 逻辑删除 + 自动填充
- Knife4j API 文档聚合
- 独立数据库：`platform`（用户/流程/运营）+ `platform_message`（消息中心）

### 系统管理（platform-user）
- 用户/角色/菜单/组织/部门/岗位 CRUD + RBAC 权限
- 字典管理 + 参数配置
- 操作日志记录 + 查询
- 动态菜单导航 + 按钮权限指令

### 流程中心（platform-workflow）
- 流程定义部署/挂起/激活/删除/编辑
- 自定义 SVG 渲染流程设计器（拖拽/缩放/撤销重做/属性面板）
- 请假申请发起/列表/详情/审批时间轴
- 待办/已办查询 + 审批/驳回/转办
- 流程监控 + 实例高亮追踪
- Flowable 6.8.1 集成 + Kafka 事件推送

### 运营管理（platform-ops）
- 独立前后端（platform-ops + platform-ops-admin）
- 租户 CRUD + 启停管理
- 对象存储配置（MinIO）
- 网关动态路由管理
- 日志审计（操作日志/登录日志/API 日志）

### 消息通知（一期：Workflow 通知）
- spring-kafka 集成（Topic: task-notify）
- 后端：TaskNotifyStore（内存存储）+ Controller API
- 前端：顶部铃铛图标 + 未读角标 + 15s轮询 + 通知弹窗
- 任务创建/完成时自动推送 Kafka 消息

### 消息中心（platform-message）— Sprint 2 核心模块

#### P0：服务搭建 ✅
- 独立 Maven 模块 `platform-message`，端口 8085，注册根 POM
- 独立数据库 `platform_message` + Flyway 独立迁移表
- Flyway 4 张表：sys_message（站内信）、sys_message_channel（渠道）、sys_message_template（模板）、sys_message_record（记录）
- 种子数据：2 个默认渠道、4 个默认模板、10 条站内信
- Gateway `/message/**` 路由 → 8085
- 从 platform-user 迁移消息代码 + 清理旧文件
- Docker 镜像构建部署（platform-message:latest）

#### P1：渠道管理 ✅
- 渠道 CRUD API（MessageChannelController）
- 渠道管理前端页面（Channel.vue）：列表/新增/编辑弹窗/JSON 配置编辑器
- 渠道测试发送功能（test-send API）
- 阿里云短信 SmsSender（占位模式，只记日志）
- 路由 `/message/channel` 已注册

#### P2：短信模板管理 ✅
- 模板 CRUD API（MessageTemplateController）
- 模板管理前端页面（Template.vue）：列表/筛选/新增/编辑/删除
- 变量定义 JSON 编辑
- 路由 `/message/template` 已注册

#### P3：消息发送引擎 ✅
- ChannelSender 接口 + ChannelSenderRegistry 策略选择器
- SiteMessageSender（站内信）+ SmsSender（短信占位）
- MessageSendService（发送处理 + 状态更新 + 重试机制）
- Kafka 异步发送（topic: message-send）+ MessageSendConsumer 消费端
- 消息记录 API（MessageRecordController）：分页/详情/发送/测试发送/重发/删除
- SendTestRequest DTO + MessageSendRequest Kafka 消息体

#### P5：前端整合 ✅
- 站内信列表页（List.vue）：类型筛选/关键词搜索/分页/全部已读/删除
- 站内信详情页（Detail.vue）：内容展示/自动标记已读/返回导航
- API 文件重构（api/message.ts）：站内信/渠道/模板/记录/测试发送 完整 API
- Layout.vue 铃铛改造：
  - 徽标合并显示流程通知 + 站内信未读数
  - 弹窗分「系统消息」+「流程通知」两栏展示
  - 系统消息最新 5 条（蓝点标记未读，点击跳转详情）
  - 「查看更多」链接跳转消息列表页
- 侧边栏菜单（V14 Flyway 迁移）：消息中心 → 消息列表/渠道配置/短信模板
- nginx.conf 新增 `/api/message/` 代理 → platform-message:8085
- Vite 代理 `/api/message` → localhost:8085

- `sys_user_menu` 表：用户直接菜单授权（运营管理员专用）
- 运营后台新增用户管理页面（CRUD + 菜单授权树 + 重置密码）
