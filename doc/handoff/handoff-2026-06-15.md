## 七、技术细节 (下次会话要知道的坑)

### InitBpmnRunner

- **不能用 `RETURNS_DEEP_STUBS`**: 跨测试 stub 串扰, 改用手动 mock chain (`@Mock ProcessDefinitionQuery` + `@Mock DeploymentBuilder`) + `@MockitoSettings(strictness = LENIENT)`
- **DocumentBuilderFactory 必须 `setNamespaceAware(true)`**: 否则 `getElementsByTagNameNS` 找不到 `bpmn:process`
- **设计原则**: 单个 BPMN 失败 catch 兜底不阻塞启动, 同 key 已存在即跳过 (避免覆盖业务方)

### Workflow day 变量兜底

- **触发条件**: 业务方启动流程时没传 `day`, 但 PROC_DEF 含 exclusive gateway 评估 `${day >= 3}`
- **修复位置**: `WorkflowInstanceService.start()` line 47 后, `if (!vars.containsKey("day") && vars.containsKey("leaveDays"))` 自动补
- **业务方无需改**: 这是后端容错, 但长期应该业务方主动传 (避免 condition 表达式变更再踩坑)

### Grafana 看板

- **exporter 实际指标**: `container_memory_rss_bytes` / `container_memory_usage_bytes` / `container_cpu_usage_nanoseconds_total` (rate 转)
- **看板用错的旧 cAdvisor 指标**: `container_memory_working_set_bytes` / `container_cpu_usage` — 已替换
- **Reload**: dashboards.yml `updateIntervalSeconds: 30` 自动 reload, 无需重启 Grafana

### 命名空间强制规则

- **编码规范 §1.1**: "强制命名空间" 行 — 任何 `com.cloudhub.*` 之外的业务包都禁止
