## 三、测试方法

### 3.1 内存采样

```bash
# 静默模式采样
docker stats --no-stream platform-user platform-auth platform-workflow \
  platform-message platform-gateway platform-ops

# 持续采样 60s, 每秒 1 次
docker stats --interval 1 platform-user > /tmp/mem_user.log 2>&1 &
docker stats --interval 1 platform-workflow > /tmp/mem_wf.log 2>&1 &
sleep 60
kill %1 %2 2>/dev/null
```

### 3.2 容器内部 JVM 详细指标

```bash
# 进入容器
docker exec platform-user sh

# 查看 JVM 堆使用
jcmd 1 GC.heap_info

# 查看 Metaspace
jcmd 1 VM.metaspace

# 触发 Full GC 看实际占用
jcmd 1 GC.run
jcmd 1 GC.heap_info
```

### 3.3 负载测试（可选）

```bash
# 用 wrk 或 ab 测试核心接口
ab -n 1000 -c 50 -p login.json -T application/json \
   http://localhost:8083/auth/login
```

## 五、注意事项

1. **采样时机**: 必须在服务稳定运行 5 分钟后采样（避免启动期峰值）
2. **负载状态**: 在空载和 50 并发两种状态下分别采样
3. **Full GC 后**: 触发 Full GC 后的内存才是真实占用
4. **JVM 版本**: 不同 OpenJDK 版本下 Metaspace 大小差异显著
