## 一、采样规范

### 1.1 采样时机

- ✅ 服务稳定运行 **5 分钟后**（避免启动期峰值）
- ✅ 在空载状态采样（无业务请求）
- ✅ Docker Desktop 环境 (8C 16G 可用, 实际分配 7.76G)

### 1.2 采样命令

```bash
# 容器内存
docker stats --no-stream --format "table {{.Name}}\t{{.MemUsage}}" | grep "platform-"

# 容器内 JVM 详细指标（需容器内有 jcmd）
docker exec platform-user jcmd 1 GC.heap_info
docker exec platform-user jcmd 1 GC.run && docker exec platform-user jcmd 1 GC.heap_info

# Actuator 指标（需端口映射正常）
curl -s http://localhost:8081/actuator/metrics/jvm.memory.used?tag=area:heap
curl -s http://localhost:8081/actuator/metrics/jvm.gc.pause
curl -s http://localhost:8081/actuator/metrics/hikaricp.connections.active
```

### 1.3 必采指标

| 指标 | 命令 | 阈值 |
|------|------|------|
| 容器内存 | `docker stats` | < Xmx × 1.3 |
| 堆使用率 | `jcmd GC.heap_info` | < 80% |
| GC 暂停 | `jcmd GC.alloc` | P99 < 100ms |
| 接口 RT | curl 观察 | P99 < 500ms |
