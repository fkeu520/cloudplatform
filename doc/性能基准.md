## 一、采样规范

### 1.1 采样时机

- ✅ 服务稳定运行 **5 分钟后**（避免启动期峰值）
- ✅ 在空载和 50 并发两种状态下分别采样
- ✅ 触发 Full GC 后看真实占用

### 1.2 采样命令

```bash
# 静默模式采样
docker stats --no-stream platform-user platform-auth platform-workflow \
  platform-message platform-gateway platform-ops

# 持续采样 60s
docker stats --interval 1 platform-user > /tmp/mem_user.log 2>&1 &

# 容器内 JVM 详细指标
docker exec platform-user sh -c "jcmd 1 GC.heap_info && jcmd 1 VM.metaspace"
docker exec platform-user sh -c "jcmd 1 GC.run && jcmd 1 GC.heap_info"  # 触发 Full GC
```

### 1.3 必采指标

| 指标 | 命令 | 阈值 |
|------|------|------|
| 容器内存 | `docker stats` | < Xmx × 1.3 |
| 堆使用率 | `GET /actuator/metrics/jvm.memory.used` | < 80% |
| GC 暂停 | `GET /actuator/metrics/jvm.gc.pause` | P99 < 100ms |
| 接口 RT | `GET /actuator/metrics/http.server.requests` | P99 < 500ms |
| HikariCP 活跃 | `GET /actuator/metrics/hikaricp.connections.active` | < max × 0.8 |
| Kafka lag | `kafka-consumer-groups.sh --describe` | < 100 |
