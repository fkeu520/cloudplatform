## Table 4

| 主要质量属性 | 详细要求 |
| 正确性 | 系统对信息发送和其他资料管理的正确性>99.7%； 通信错误对业务结果正确性的影响为0 |
| 健壮性 | 系统对不符合业务管理规则的输入条件可以过滤； |
| 可靠性 | 系统保障97%以上的时间可用； |
| 性能，效率 | 系统应在不耽误相关人员工作的足够短的时间内做出响应； |
| 易用性 | 系统符合相关操作员的使用习惯； |
| 清晰性 | 系统给出的信息足够地明确，易于理解，绝对禁止对底层的错误信息显示给最终用户 |
| 安全性 | 系统具有登陆和权限保护机制，对核心数据访问具有严格的限制； |
| 可扩展性 | 系统可以比较容易地增加功能或者提高处理能力； |
| 可移植性 | 当系统的服务器平台改变时，系统的改动代价最小； |
