## 三、详细安装步骤

### 3.1 安装 Git

**下载链接：** https://git-scm.com/download/win

**操作步骤：**

1. 下载 `Git-2.43.x-64-bit.exe`
2. 双击安装，一路 Next 即可
3. 勾选 "Add to PATH"
4. 完成安装

**验证：**

```bash
git --version
# 应显示：git version 2.43.x
```

### 3.2 安装 JDK 17

**下载链接：** https://adoptium.net/temurin/releases/?version=17

**操作步骤：**

1. 下载 `jdk-17.x.x+x_windows_x64_hotspot.msi`
2. 双击安装，默认路径 `C:\Program Files\Eclipse Adoptium\jdk-17.x.x+x`
3. 配置环境变量：

```bash
# 系统环境变量
JAVA_HOME = C:\Program Files\Eclipse Adoptium\jdk-17.0.10+7
PATH = %JAVA_HOME%\bin;%PATH%
```

**验证：**

```bash
java --version
# 应显示：openjdk 17.0.x "Temurin"
javac --version
# 应显示：javac 17.0.x
```

### 3.3 安装 Maven 3.9

**下载链接：** https://maven.apache.org/download.cgi

**操作步骤：**

1. 下载 `apache-maven-3.9.x-bin.zip`
2. 解压到 `D:\tools\maven`（任意目录）
3. 配置环境变量：

```bash
# 系统环境变量
MAVEN_HOME = D:\tools\maven
PATH = %MAVEN_HOME%\bin;%PATH%
```

4. 配置 Maven 镜像（可选，加速下载）：

```xml
<!-- D:\tools\maven\conf\settings.xml -->
<mirrors>
  <mirror>
    <id>aliyun</id>
    <mirrorOf>central</mirrorOf>
    <name>Aliyun Maven</name>
    <url>https://maven.aliyun.com/repository/central</url>
  </mirror>
</mirrors>
```

**验证：**

```bash
mvn --version
# 应显示：Apache Maven 3.9.x
```

### 3.4 安装 Node.js 18

**下载链接：** https://nodejs.org/

**操作步骤：**

1. 下载 `node-v18.x.x-x64.msi`
2. 双击安装，默认安装即可
3. 配置 npm 镜像（国内加速）：

```bash
npm config set registry https://registry.npmmirror.com
```

**验证：**

```bash
node --version
# 应显示：v18.x.x
npm --version
# 应显示：9.x.x
```

### 3.5 安装 Docker Desktop

**下载链接：** https://www.docker.com/products/docker-desktop/

**操作步骤：**

1. 下载 `Docker Desktop Installer.exe`
2. 双击安装，需要 WSL2 支持（Windows 自动安装）
3. 重启电脑
4. 启动 Docker Desktop，等待小鲸鱼图标稳定

**验证：**

```bash
docker --version
# 应显示：Docker version 24.x.x

docker-compose --version
# 应显示：Docker Compose version v2.x.x

docker run hello-world
# 应显示：Hello from Docker!
```

> ⚠️ **常见问题**：Docker 启动失败  
> **解决**：打开 "Windows 功能" → 勾选 "Linux 子系统(WSL2)" → 重启电脑

### 3.6 安装 IntelliJ IDEA

**下载链接：** https://www.jetbrains.com/idea/download/

**操作步骤：**

1. 下载 `ideaIU-2024.x.exe`（Community 免费版足够）
2. 双击安装，勾选 "Add to PATH"
3. 安装完成后，激活（可选，社区版无需激活）

**推荐插件：**

| 插件名称 | 用途 |
|---------|------|
| Alibaba Java Coding Guidelines | 阿里巴巴编码规范检查 |
| MyBatisX | MyBatis 映射文件跳转 |
| Maven Helper | Maven 依赖分析 |
| Gitmoji PLUS | Git 提交表情 |
| .env files support | 环境变量文件支持 |

创建文件：`D:\work\AI\output\platform\docker-compose.yml`

```yaml

  # ============ MySQL 8.0 ============
  mysql:
    image: mysql:8.0
    container_name: platform-mysql
    restart: unless-stopped
    environment:
      MYSQL_ROOT_PASSWORD: root123456
      MYSQL_DATABASE: platform
      MYSQL_USER: platform
      MYSQL_PASSWORD: platform123
      TZ: Asia/Shanghai

      - "3306:3306"
    volumes:
      - mysql-data:/var/lib/mysql
      - ./docker/mysql/init.sql:/docker-entrypoint-initdb.d/init.sql
      - ./docker/mysql/my.cnf:/etc/mysql/conf.d/my.cnf
    command: --default-authentication-plugin=mysql_native_password --character-set-server=utf8mb4 --collation-server=utf8mb4_unicode_ci
    healthcheck:
      test: ["CMD", "mysqladmin", "ping", "-h", "localhost"]
      interval: 10s
      timeout: 5s
      retries: 5

  # ============ Redis 7 ============
  redis:
    image: redis:7-alpine
    container_name: platform-redis
    restart: unless-stopped
    ports:
      - "6379:6379"
    volumes:
      - redis-data:/data
      - ./docker/redis/redis.conf:/usr/local/etc/redis/redis.conf
    command: redis-server /usr/local/etc/redis/redis.conf
    healthcheck:
      test: ["CMD", "redis-cli", "ping"]
      interval: 10s
      timeout: 5s
      retries: 5

  # ============ Kafka 3.6 ============
  kafka:
    image: bitnami/kafka:3.6
    container_name: platform-kafka
    restart: unless-stopped
    ports:
      - "9092:9092"
    environment:
      KAFKA_CFG_NODE_ID: 0
      KAFKA_CFG_PROCESS_ROLES: controller,broker
      KAFKA_CFG_CONTROLLER_QUORUM_VOTERS: 0@kafka:9093
      KAFKA_CFG_LISTENERS: PLAINTEXT://:9092,CONTROLLER://:9093
      KAFKA_CFG_LISTENER_SECURITY_PROTOCOL_MAP: CONTROLLER:PLAINTEXT,PLAINTEXT:PLAINTEXT
      KAFKA_CFG_CONTROLLER_LISTENER_NAMES: CONTROLLER
      KAFKA_CFG_LISTENER_ADVERTISED_LISTENERS: PLAINTEXT://localhost:9092
      KAFKA_CFG_INTER_BROKER_LISTENER_NAME: PLAINTEXT
      KAFKA_CFG_AUTO_CREATE_TOPICS_ENABLE: "true"
      ALLOW_PLAINTEXT_LISTENER: "yes"
    volumes:
      - kafka-data:/bitnami/kafka
    healthcheck:
      test: ["CMD-SHELL", "kafka-topics.sh --bootstrap-server localhost:9092 --list"]
      interval: 30s
      timeout: 10s
      retries: 5

  # ============ Nacos 2.2 ============
  nacos:
    image: nacos/nacos-server:v2.2.3
    container_name: platform-nacos
    restart: unless-stopped
    environment:
      MODE: standalone
      SPRING_DATASOURCE_PLATFORM: mysql
      MYSQL_SERVICE_HOST: mysql
      MYSQL_SERVICE_PORT: 3306
      MYSQL_SERVICE_DB_NAME: platform
      MYSQL_SERVICE_USER: platform
      MYSQL_SERVICE_PASSWORD: platform123
      NACOS_AUTH_ENABLE: false
      JVM_XMS: 512m
      JVM_XMX: 512m
    ports:
      - "8848:8848"
      - "9848:9848"
    volumes:
      - nacos-data:/home/nacos/data
      - nacos-logs:/home/nacos/logs
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:8848/nacos/v1/console/health/readiness"]
      interval: 15s
      timeout: 10s
      retries: 3

  # ============ MinIO ============
  minio:
    image: minio/minio:latest
    container_name: platform-minio
    restart: unless-stopped
    ports:
      - "9000:9000"
      - "9001:9001"
    environment:
      MINIO_ROOT_USER: minioadmin
      MINIO_ROOT_PASSWORD: minioadmin123
      MINIO_DEFAULT_BUCKETS: platform
    volumes:
      - minio-data:/data
    command: server /data --console-address ":9001"
    healthcheck:
      test: ["CMD", "mc", "ready", "local"]
      interval: 15s
      timeout: 10s
      retries: 3

  # ============ Elasticsearch 8.x ============
  elasticsearch:
    image: docker.elastic.co/elasticsearch/elasticsearch:8.12.0
    container_name: platform-elasticsearch
    restart: unless-stopped
    environment:
      - discovery.type=single-node
      - xpack.security.enabled=false
      - ES_JAVA_OPTS=-Xms1g -Xmx1g
      - TZ=Asia/Shanghai
    ports:
      - "9200:9200"
      - "9300:9300"
    volumes:
      - es-data:/usr/share/elasticsearch/data
    healthcheck:
      test: ["CMD-SHELL", "curl -s http://localhost:9200 | grep -q ' tagline'"]
      interval: 30s
      timeout: 10s
      retries: 5

    image: docker.elastic.co/kibana/kibana:8.12.0
    container_name: platform-kibana
    restart: unless-stopped
    environment:
      - ELASTICSEARCH_HOSTS=http://elasticsearch:9200

volumes:
  mysql-data:

  es-data:
```

## 九、常见问题与解决

### 问题 1：Docker 启动失败

**症状：** Docker Desktop 启动后报错 "WSL2 installation is incomplete"

**解决：**

```powershell
# 以管理员身份打开 PowerShell
wsl --install -d Ubuntu-22.04
# 重启电脑
```

---

### 问题 2：MySQL 连接被拒绝

**症状：** `Connection refused: connect`

**排查步骤：**

```bash
# 1. 检查容器是否运行
docker ps | grep mysql

# 2. 查看 MySQL 日志
docker logs platform-mysql

# 3. 检查端口占用
netstat -an | findstr 3306

# 4. 手动测试连接
mysql -h localhost -u root -proot123456
```

**解决：**

```bash
# 如果容器未运行，启动它
docker-compose up -d mysql

# 如果端口被占用，修改 docker-compose.yml 中的端口映射
ports:
  - "3307:3306"  # 改为 3307
```

---

### 问题 3：Kafka 连接超时

**症状：** `kafka.common.errors.TimeoutException: Exceeded 30s while waiting for node`

**解决：**

```bash
# 1. 等待 Kafka 完全启动（约 30 秒）
docker logs platform-kafka

# 2. 创建测试 Topic
docker exec platform-kafka kafka-topics.sh --bootstrap-server localhost:9092 --create --topic test
```
