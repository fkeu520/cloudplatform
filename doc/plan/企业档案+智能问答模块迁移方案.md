### 3.3 核心流程 (RAG)

```
用户提问 → 文本嵌入(SiliconFlow) → FAISS向量搜索 → 取Top-K相关段落
    → 组装Prompt → DeepSeek LLM → 生成回答
```

### 3.4 集成架构

**前后端分离部署** (与 platform-admin / platform-ops-admin 一致):

| 组件 | 方案 |
|------|------|

| 前端 | Vue 3 独立 SPA → `platform-kefu-frontend` 容器 (:80) |

| API 路由 | gateway `/api/kefu/**` → platform-kefu:8000 |
| 前端路由 | gateway `/kefu/**` → platform-kefu-frontend:80 |
| 容器化 | Docker + ghcr.io (双镜像) |
| 认证 | 复用平台 JWT Token (删除自有auth) |

**架构图**:
```

  ├── /kefu/**     → platform-kefu-frontend:80 (Vue 3 SPA)

```

#### 3.4.2 四项改造详细说明

**① 权限验证**

| 当前方案 | 改造后 |
|---------|--------|
| 自有 auth.py (用户名密码登录) | 复用平台 JWT Token |
| 自有 login/login.html | 从 platform-admin 发送 JWT Header |
| API 全开放 | `/api/kefu/*` 全部校验 JWT |

改造方式:
- 删除 `api/auth.py`、`core/security.py`
- 新增 `app/middleware/auth_middleware.py`: 解析 `Authorization: Bearer <token>` → 调用平台 RSA 公钥验证 → 提取 userId/username → 注入 request.state.user
- 与 platform-auth 共用同一套 JWT_SECRET/RSA 密钥 (环境变量注入)

**② 菜单结构**

在 platform-admin 中新增:
```
智能问答                    (一级菜单, icon=fa-comment-dots)
├── 问答对话               (Chat.vue, /kefu/chat)
├── 知识库                 (Knowledge.vue, /kefu/knowledge)
└── 数据看板               (Dashboard.vue, /kefu/dashboard)
```

- 前端页面: 直接引用 kefu 前端 `frontend/src/views/` 中的 Chat.vue / Knowledge.vue / Dashboard.vue
- API 适配: `api/kefu.ts` 封装，统一加 JWT Header → 走 gateway
- 路由注册: `router/index.ts` 加 3 条路由

**③ MySQL 持久化**

| 组件 | SQLite | MySQL |
|------|--------|-------|
| 数据库文件 | `data/metadata.db` | platform_kefu (新库) |
| 连接方式 | 本地文件 | Redis 连接池 (aiomysql) |
| 表结构 | chunks, documents, users, ask_logs | 同结构，加到 `docker/mysql/init.sql` |
| 向量索引 | FAISS 文件 `data/vector_index/` | 保持 FAISS 文件不变 (向量不适合放 MySQL) |

FAISS 向量索引文件改为挂载 Docker volume 持久化, 不放入 MySQL。

**④ Docker 化 + Gateway 路由**

```yaml
# docker-compose.yml 新增
platform-kefu:
  image: ghcr.io/fkeu520/cloudplatform/platform-kefu:latest
  build:
    context: ./code/platform-kefu
  ports:
    - "8050:8000"
  environment:
    - MYSQL_HOST=platform-mysql
    - MYSQL_PORT=3306
    - MYSQL_DATABASE=platform_kefu
    - MYSQL_USER=platform
    - MYSQL_PASSWORD=platform123
    - JWT_SECRET=${JWT_SECRET}
    - SILICONFLOW_API_KEY=${SILICONFLOW_API_KEY}
    - DEEPSEEK_API_KEY=${DEEPSEEK_API_KEY}
  volumes:
    - kefu-vector-index:/app/data/vector_index
  depends_on:
    platform-mysql: { condition: service_healthy }
```

Gateway 路由:
```yaml
# gateway.yml 新增
- id: platform-kefu
  uri: lb://platform-kefu:8000
  predicates:
    - Path=/api/kefu/**, /api/ask/**
```

#### 3.4.3 文件存储: MinIO 改造

| 当前方案 | 改造后 |
|---------|--------|
| 本地 `data/documents/` 目录 | MinIO bucket `kefu-docs` |
| 文件路径存 SQLite | 文件对象 key 存 MySQL |
| 容器重启文件丢失 | Docker volume 持久化 |

Python 端使用 `minio` 库直接上传/下载:
```python
from minio import Minio

client = Minio(
    endpoint=settings.MINIO_ENDPOINT,    # platform-minio:9000
    access_key=settings.MINIO_ACCESS_KEY,
    secret_key=settings.MINIO_SECRET_KEY,
    secure=False
)
# 上传: client.put_object("kefu-docs", object_name, file_stream, length)
# 下载: client.get_object("kefu-docs", object_name)
```
