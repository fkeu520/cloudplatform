### 🔴 P1 — 多机部署前必须修复

#### 1. MyBatis-Plus workerId/datacenterId 未显式配置  ✅ **已修复并验证**
- **现状（修复前）**：`application.yml` 仅配置 `id-type: assign_id`，未设置 `worker-id` / `datacenter-id`
- **默认行为**：MP 3.5.5 `DefaultIdentifierGenerator` 从容器 MAC 地址和 IP 哈希派生 → 单机部署下所有服务拿到**相同的 workerId+datacenterId**
- **风险**：
  - 单机部署：每 JVM 独立 sequence 计数器（12 位 = 4096/ms），单服务 ≤ 4096 inserts/ms 安全，多服务并发总和若超 4096/ms 会碰撞
  - **多机部署**：两台机器的 MAC/IP 不同 → 派生不同的 workerId → 看似无碰撞，但如果两机时钟回拨或 NTP 漂移会导致 ID 异常

**修复 (2026-06-02)**:
- `MybatisPlusConfig.java` 新增 `@Bean IdentifierGenerator identifierGenerator(...)`,通过 `@Value` 读取 yml `mybatis-plus.snowflake.worker-id/datacenter-id`,校验 0-31 范围
- 5 个服务 yml 加 snowflake 配置:`${MYBATIS_PLUS_SNOWFLAKE_WORKER_ID:N}` 支持环境变量覆盖
- `docker-compose.yml` 注入差异化 env vars

**服务分配**:
| 服务 | workerId | datacenterId |
|------|----------|--------------|
| platform-user | 1 | 1 |
| platform-ops | 4 | 1 |
| platform-message | 1 | 2 |
| platform-workflow | n/a (无 @TableId) | n/a |
| platform-auth | n/a (无 mybatis-plus 依赖) | n/a |

**E2E 验证 (3/3 服务通过)**:
| 服务 | 雪花 ID | 二进制提取 datacenter / worker | 结果 |

| platform-user | dept `2061637441810468865` | datacenter=1, worker=1 | ✅ PASS |
| platform-user | post `2061637448580075522` | datacenter=1, worker=1 | ✅ PASS |

#### 7.1 H2 mock 桩设计

**问题**: 集成测试用 H2 (SpringBootTest 默认), MySQL 8 `WITH RECURSIVE` 在 H2 兼容性:
- H2 1.4.x: ❌ 不支持
- H2 2.0+: ✅ 支持 (但**语法有差异**: H2 子查询顺序、关键字位置)

**项目 H2 版本**: 由 `spring-boot-starter-test` 引入, 跟随 Spring Boot 3.2.x 默认 H2 2.x (大概率支持)

**3 候选方案对比**:

| 方案 | 实施 | 优 | 缺 |
|------|------|-----|----|
| **A. H2 2.x 原生** | mapper 写 MySQL 8 CTE, 集成测试 H2 跑 | 简洁, 1 套代码 | H2 语法差异可能跑不通, 需小调整 |
| **B. @Profile 切换** | `DeptsTreeQueryService` 接口 + 2 实现 (CTE + DFS), @Profile 切换 | 100% 兼容 | 代码冗余 2 份 |
| **C. Mockito mock** | 单测 mock DeptMapper, 集成测试不覆盖 CTE | 简单 | 集成测试覆盖弱, 端到端靠 docker 真 MySQL |

**推荐**: **A + C 组合** (先试 A, 不通再 fallback B)

1. mapper 写 MySQL 8 CTE (MyBatis `@Select` 注解)
2. 单测用 Mockito mock DeptMapper (项目现有模式)
3. 集成测试: 先试 H2 2.x `WITH RECURSIVE`, 跑通 → 端到端 SQL 验证
4. H2 跑不通 → fallback B (加 `@Profile("!test")` 切换实现)
5. 端到端真 MySQL 8: `docker exec platform-mysql` 跑 CTE, 验证生产等价

**关键 SQL 模板** (MyBatis `@Select` 注解, 写入 `DeptMapper.java`):

```java
@Select("""
    WITH RECURSIVE dept_tree AS (
        SELECT id FROM sys_dept
        WHERE id = #{rootDeptId}
          AND deleted = 0
          AND (#{tenantId} IS NULL OR tenant_id = #{tenantId})
        UNION ALL
        SELECT d.id FROM sys_dept d
        INNER JOIN dept_tree dt ON d.parent_id = dt.id
        WHERE d.deleted = 0
          AND (#{tenantId} IS NULL OR d.tenant_id = #{tenantId})
    )
    SELECT id FROM dept_tree
    """)
@Options(resultType = Long.class)
List<Long> selectChildDeptIdsByCte(
    @Param("rootDeptId") Long rootDeptId,
    @Param("tenantId") Long tenantId);
```
