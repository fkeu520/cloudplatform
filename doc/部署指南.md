## 3. 后端部署

### 3.1 配置文件

修改 `code/platform-server/platform-common/src/main/resources/application.yml`：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/platform_default?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai
    username: root
    password: your_password
    driver-class-name: com.mysql.cj.jdbc.Driver

  redis:
    host: localhost
    port: 6379
    password: 
    database: 0

  kafka:
    bootstrap-servers: localhost:9092
    consumer:
      group-id: platform-group

server:
  port: 8080
  servlet:
    context-path: /

# JWT 配置
jwt:
  secret: your_jwt_secret_key_here
  expiration: 86400000  # 24 小时

# 物联中台配置
iot:
  mqtt:
    broker-url: tcp://localhost:1883
    username: 
    password: 
  edge:
    enabled: true
    k3s-url: http://localhost:6443

# 数据中台配置
data:
  elasticsearch:
    hosts: localhost:9200
  influxdb:
    url: http://localhost:8086
    database: iot_data
```

### 3.2 编译打包

```bash
cd code/platform-server
mvn clean package -DskipTests
```

### 3.3 启动后端

**方式一：直接运行 JAR**

```bash
java -jar platform-admin/target/platform-admin-1.0.0.jar
```

**方式二：Maven 运行**

```bash
cd platform-admin
mvn spring-boot:run
```

**方式三：Docker 运行**

```bash
docker build -t platform-admin:1.0.0 .

  -e SPRING_DATASOURCE_URL=jdbc:mysql://mysql:3306/platform_default \
  -e SPRING_REDIS_HOST=redis \
```

- [`L2_Spring精简优化方案.md`](L2_Spring精简优化方案.md) — 完整方案（3 阶段、6 服务具体改动）

### 8.4 Nginx 配置（生产）

```nginx
upstream backend {
    least_conn;
    server 192.168.1.10:8080 weight=3;
    server 192.168.1.11:8080 weight=3;
    server 192.168.1.12:8080 backup;
}

server {
    listen 80;
    server_name api.yourdomain.com;

    location / {
        proxy_pass http://backend;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_connect_timeout 60s;
        proxy_read_timeout 60s;
    }
}

server {
    listen 443 ssl http2;
    server_name api.yourdomain.com;

    ssl_certificate /etc/nginx/ssl/api.yourdomain.com.crt;
    ssl_certificate_key /etc/nginx/ssl/api.yourdomain.com.key;

    location / {
        proxy_pass http://backend;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

## 10. 常见问题

### 10.1 后端启动失败

**问题：** 数据库连接失败  
**解决：**
1. 检查 MySQL 是否运行：`systemctl status mysqld`
2. 检查配置文件中的数据库连接信息
3. 检查防火墙：`firewall-cmd --list-ports`

### 10.2 前端无法访问后端

**问题：** 跨域错误  
**解决：**
1. 检查 `vite.config.ts` 代理配置
2. 检查后端 CORS 配置
3. 确认后端服务已启动

### 10.3 设备无法接入

**问题：** MQTT 连接失败  
**解决：**
1. 检查 EMQ X 是否运行：`docker ps | grep emqx`
2. 检查 MQTT Broker 地址配置
3. 检查设备认证信息

### 10.4 登录失败

**问题：** JWT 验证失败  
**解决：**
1. 检查 `application.yml` 中的 JWT secret
2. 清除浏览器缓存
3. 重新登录获取新 token
